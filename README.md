# Kyoong Web Cam ★

Gacha photo booth web app — Y2K kawaii Tamagotchi aesthetic.

## Project structure

```
kyoong-webcam/
├── index.html       ← entry point
├── css/
│   └── styles.css   ← design tokens + all styles
├── js/
│   └── app.js       ← gacha logic, camera, strip capture
└── assets/          ← place custom frame PNGs here (optional)
```

## Usage

Open `index.html` in a browser. Camera access required for photos.
